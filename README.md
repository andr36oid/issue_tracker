# andr36oid issue tracker

Problems and ideas for andr36oid on the **R36S, R36S Plus, R46H and R50S**, with
the files from the `Panels` or `Devices` folder on the BOOT drive.

[Report a problem or suggest something](https://github.com/andr36oid/issue_tracker/issues/new/choose)

Is your console a clone, or does it need a folder from `Experimental` (K36, G80,
R36 Max, R36 Ultra, Soy Sauce and others)? Use the
[clone issue tracker](https://github.com/andr36oid/clone_issue_tracker/issues/new/choose)
instead.

## Problem reports

A problem report holds the logs that show what went wrong. Attach one whenever
you can:

- If the console works: **Settings > System > Problem report**. It is saved on
  the EASYROMS drive, in the folder `andr36oid-reports`.
- If it doesn't start: put an empty file called `make-report.txt` at the top of
  the BOOT drive and start the console. Wait 10 minutes, then look for
  `andr36oid-reports` on BOOT or EASYROMS. `make-report-result.txt` on BOOT says
  where the report went.
